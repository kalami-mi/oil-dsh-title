# oil-dsh-title

让 DeepSeek Harness 桌面端的会话标题跟上你正在做的事情。每轮对话结束后，参考最近 3～5 轮内容判断是否更新标题；会话再多，也更容易找到。

## 一眼看出正在做什么

Harness 自带的标题只取**第一条消息**的前几个词，聊着聊着就对不上号了。装上本插件后：

| Harness 原来的标题 | 更容易找回的标题 |
| --- | --- |
| 帮我修复邮箱注册的验证码过 | 🧩 邮箱注册｜验证码修复 |
| 先不做这个了，我想给 Ori | 🎬 Orion 评测视频｜标题策划 |
| 你在 Windows 上工作，工作目录 | 🧩 oil-codex-title｜Windows 适配 |

统一采用 **「类别 emoji + 对象｜目标」**，先找对象，再看正在做什么。

- **对象在前**：把“登录表单”“CRT 转场”等辨识词放到前面，默认省略工作目录名这类外层项目名。
- **类别固定**：🎬 内容制作、🧩 工具开发、🔎 对比调研、🎨 页面设计、📝 方法整理、📅 日程安排、⚙️ 环境配置、💬 一般讨论。
- **名称稳定**：标题准确就保持原样；“继续”“推送”“补个测试”不会取代主线。
- **跟随你的语言**：按你最近几轮的主要语言命名，产品名保留原文。
- **不打扰对话**：命名在后台单独请求，不往会话里加任何消息，不影响当前回答。
- **省用量**：稳定标题后的纯确认（“好的”“收到”）最多连续 2 轮不调用模型；内容没变化时不重复判断。新会话第一轮会先按首条消息给个早期标题，轮次结束再带着回答校正一次。
- **你说了算**：你手动改的名字会被固定，插件永远不会覆盖；`/title` 可预览、固定、暂停。

## 安装

要求：DeepSeek Harness 桌面端（已在 `0.2.0-rc.2` 上验证，见[兼容性](docs/使用与边界.md#兼容性与验证范围)）。

1. 生成干净的安装目录（不含开发用的 `node_modules`）：

   ```powershell
   node scripts/pack.mjs
   ```

   会得到 `dist\oil-dsh-title`，并打印它的绝对路径。

2. 打开 Harness 桌面端，侧边栏进入 **插件（Plugins）**，选择安装，粘贴上一步打印的**绝对路径**，安装并启用。
3. 等提示应用完成（热重载开启时立即生效，否则重启桌面端）。
4. 新开一个会话正常聊天，聊完一轮后看侧边栏标题。

详细步骤、手动方式与卸载见 [安装与验证](docs/安装与验证.md)。

默认沿用会话正在使用的模型来命名；想固定一个便宜的模型，见 [使用与边界](docs/使用与边界.md#配置)。命名会消耗你当前账号的模型额度。

## 日常怎么用

在会话输入框里：

```text
/title              立即按最近对话检查并更新标题
/title preview      只预览候选标题，不写入
/title set 我的复盘  手动设置并固定标题
/title lock         固定当前标题
/title unlock       恢复自动命名
/title pause        暂停所有会话的自动命名（/title resume 恢复）
/title status       查看状态与模型用量
```

在侧边栏手动改名同样会固定标题。

## 开发

```powershell
python scripts/extract-runtime.py "D:\DeepSeek Harness"   # 把桌面端自带的运行时解到 node_modules，仅测试用
npm test
```

测试对着真实的 `cordis`、会话存储、标题服务和命令运行时运行，只把模型换成可编排的假实现。另有一个真实端到端脚本：

```powershell
node scripts/e2e-real-dsh.mjs
```

它用桌面端自带的 `dsh` 启动器在隔离的临时目录里安装并运行本插件（模型是本机假服务），不碰你真实的 `~/.dsh`。
